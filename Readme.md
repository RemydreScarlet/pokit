# Pokit Processor

---

## 1. コンセプト

**「ポケットに入る1ドルのLinuxもうごくチップ」**
汎用的なマイコンとしての用途に加え、ハードウェアレベルのAIアクセラレーションとLinux実行環境を、極小のダイサイズで実現します。

## 2. ハードウェア・アーキテクチャ

* **ISA:** RISC-V (RV32IMA)
* **構造:** インオーダー・パイプライン（5段） ＋ 擬似OoO（インターリーブ・マルチスレッディング ＋ スコアボード）
* **特徴:**
* **2-Thread Interleaving:** 計算機を1つに統合し、レジスタセットを2つ持つことで、パイプライン・ストールをハードウェア的に排除。
* **Posit演算器:** 従来のFPUを廃し、独自実装の「Posit 8 & Bfloat16」演算器を搭載。AIの推論精度を維持しつつ、回路面積を最小化。
* **メモリ保護:** MMUを積まず、超軽量な「ベース・バウンド方式」のセグメンテーションを採用し、Linux（uClinux）のマルチタスク実行を実現。


* **メモリ:** 1MBの内蔵SRAM（外部Flashを介さない爆速・省電力実行）。
* **製造プロセス:** 28nm / 40nm CMOS（枯れた技術で低コスト量産）。

## 4. 開発ロードマップ

1. **RTL設計:** RISC-Vコア＋Posit演算器＋インターリーブ機構のChisel/Verilog記述。
2. **検証:** FPGAを用いたスコアボード・分岐予測の動作検証。
3. **ソフトウェア:** uClinuxカーネルのベース・バウンド方式への移植とBuildroot環境構築。
4. **プロトタイプ:** 40nm/28nmシャトル便でのテストチップ製造。
